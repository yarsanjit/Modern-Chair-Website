# 🪑 Modern Chair – Product Landing Page

A stylish and responsive **Modern Chair Product Landing Page** built using HTML and CSS. This project showcases a modern furniture product with multiple color variations, product details, pricing information, and an Add to Cart button.

## ✨ Features

- **Modern UI Design:** Clean and elegant furniture product layout.
- **Product Information:** Displays the product name, price, and original price.
- **Color Selection:** Choose from six different chair color variations.
- **Product Description:** View the product description and specifications.
- **Product Details:** Displays chair dimensions and weight.
- **Interactive Tabs:** Switch between Description and Details sections.
- **Add to Cart Button:** Includes a styled shopping cart button.
- **Font Awesome & Unicons:** Uses icon libraries for visual enhancements.
- **Favicon:** Includes a custom website favicon.
- **Responsive Layout:** Designed to provide a visually appealing experience across screen sizes, depending on the CSS implementation.

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage.
- **CSS3** – Styling, layout, animations, and color variations.
- **Font Awesome** – Icon library.
- **Unicons** – Shopping cart icon.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the Project Directory

```bash
cd Modern-Chair
```

### 3. Open the Project

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.
